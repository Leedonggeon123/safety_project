# SafeEye - 안전모 착용 탐지 프로그램

영상에서 작업자의 **안전모 착용(helmet) / 미착용(head)** 을 AI(YOLOv8)로 탐지하고,
미착용이 일정 시간 이어지면 **경고를 표시하고 기록**하는 윈도우 프로그램입니다. (개인 프로젝트, 이동건)

관련 문서(개발계획서, 요구사항분석서, 개발일정표, DB정의서, 목업)는
`Desktop\개인 프로젝트\안전모 AI비전 검사 게시서류` 폴더에 있습니다.

---

## 1. 전체 구조 (쉽게 말하면)

```
[서버 PC, WSL]                      [내 PC, 윈도우]
 데이터셋(Hard Hat Workers)           SafeEye 앱 (C# 윈폼)  <-- 화면, 기록 저장(SQLite)
        │ 학습 (train.py)                   │  JSON 한 줄씩 주고받음
        ▼                                   ▼
   best.pt (학습된 모델)  ── USB로 복사 ──>  탐지 엔진 (Python, detect_engine.py)
                                            └ 영상 → 프레임마다 탐지 → 알림 판단
```

| 부분 | 하는 일 | 위치 |
|---|---|---|
| 학습 | 서버에서 YOLOv8을 학습해 `best.pt` 를 만든다 | `server/` |
| 탐지 엔진 | 영상을 읽어 프레임마다 helmet/head 를 찾고, 미착용이 3초 이상 이어지면 알림을 낸다 | `engine/detect_engine.py` |
| 앱 | 화면 4개(영상 탐지·기록 조회·통계·설정), 알림 기록 저장 | `app/SafeEye/` |
| 데이터 | Roboflow Hard Hat Workers v5 (Public Domain) | `data/hardhat/` |
| 모델 | 학습된 모델 | `models/best.pt` |

## 3. 앱 실행하기

1. `실행.bat` 을 더블클릭합니다. (처음에는 앱을 자동으로 빌드하느라 잠시 걸립니다)
2. 아래 상태 줄에 **`엔진 준비 완료 (cpu)`** 가 나올 때까지 기다립니다. (보통 몇 초)
3. 도구 줄의 **[영상 열기]** 로 영상을 고르고 **[탐지 시작]** 을 누릅니다.
   - 시험용 영상: `videos/demo_head.mp4` (미착용 2명, 3초 뒤 경고), `videos/demo_helmet.mp4` (착용, 경고 없음)
4. 화면에서 확인할 것
   - 영상 위 **초록 박스 = 착용(helmet)**, **빨강 박스 = 미착용(head)**
   - 오른쪽 **판정 표시**: 안전(초록) / 미착용 N명(빨강)
   - **최근 알림** 목록에 미착용 알림이 쌓이고, 자동으로 DB에 저장됩니다.
5. 오른쪽 위 버튼으로 화면을 바꿉니다: **기록 조회** (저장된 알림 검색, 캡처 이미지 확인, CSV 내보내기), **통계** (착용/미착용 비율, 영상별 건수, 신뢰도 추이), **설정**.

> 영상 경로에 한글이 있으면 영상을 못 열 수 있습니다. 영상은 `videos/` 폴더에 두는 것을 권장합니다.

### 웹캠으로 실시간 탐지하기

1. 웹캠을 USB에 연결합니다.
2. 도구 줄의 **[웹캠 켜기]** 를 누르면 바로 탐지가 시작됩니다. (끝이 없으므로 **[탐지 중지]** 로 마칩니다)
3. 안전모를 쓰고 벗어 보면 박스와 판정이 바뀝니다. 미착용이 설정 시간(기본 3초) 이어지면 경고가 뜨고 기록됩니다.
4. 웹캠 번호는 **설정 > 영상** 의 '웹캠 번호'(기본 0)입니다. 웹캠이 여러 개일 때 바꿉니다.

화면이 검게 나오거나 웹캠이 안 열리면 아래 진단을 실행하세요. 번호별로 열리는지와 화면 밝기(0~255)를 보여 줍니다.

```
.venv\Scripts\python engine\camera_check.py
```

- 밝기가 20 미만이면 렌즈 덮개, 개인정보 보호 셔터, 조명을 확인하세요.
- 윈도우 설정 > 개인 정보 및 보안 > 카메라 에서 '데스크톱 앱이 카메라에 액세스하도록 허용' 이 켜져 있어야 합니다.
- 웹캠은 CPU 부담을 줄이려고 3프레임마다 한 장씩 분석합니다. (평균 처리 약 0.12초/장)

## 4. 모델 학습하고 교체하기

지금 `models/best.pt` 는 **서버(RTX 5090, WSL)에서 학습한 n 모델**입니다. (`models/best_n.pt` 와 같은 파일)
test 사진 706장 기준 결과:

| 모델 | mAP50 | head(미착용) 재현율 | head 정밀도 | helmet 재현율 |
|---|---|---|---|---|
| n (사용 중) | 0.975 | 0.927 | 0.943 | 0.949 |
| s | 0.974 | 0.934 | 0.939 | 0.948 |

n 과 s 의 정확도가 거의 같아서, 이 PC(CPU)에서 더 빠른 **n** 을 쓰고 있습니다.
(예전에 앱 시험용으로 내 PC에서 짧게 학습했던 임시 모델은 head 재현율 0.64 였고, 이미 교체했습니다.)

모델을 다시 학습해서 바꾸려면:

1. `server/README_서버학습.md` 를 보고 서버(WSL)에서 `python train.py --size n` 등을 실행합니다.
2. 결과 `output/best_n.pt` (또는 s, m)를 내 PC `models/` 폴더에 **`best.pt`** 라는 이름으로 복사합니다.
3. 앱에서 **도구 > 엔진 다시 시작** 은 필요 없습니다. 다음 탐지부터 새 모델이 쓰입니다.
4. 학습 결과의 mAP, head 재현율을 요구사항 분석서의 "정확도" 칸에 적습니다.

## 5. 개발 환경과 직접 빌드하기

| 항목 | 내용 |
|---|---|
| 앱 | C# .NET 10 (WinForms), Microsoft.Data.Sqlite |
| 엔진 | Python 3.14 (`.venv`), ultralytics(YOLOv8), OpenCV |
| DB | SQLite (`runs`, `alerts` 2개 표) - DB정의서 참고 |

```bash
# 앱 빌드
dotnet build -c Release app/SafeEye

# 엔진만 단독 시험 (앱 없이)
.venv\Scripts\python engine\detect_engine.py --video videos\demo_head.mp4 --model models\best.pt
```

### 코드 읽는 순서 (처음 보는 사람용)
1. `engine/detect_engine.py` : 맨 위 주석에 앱과 주고받는 메시지 형식이 있습니다. (한 줄에 JSON 하나)
2. `app/SafeEye/Program.cs` → `MainForm.cs` : 창과 화면 전환
3. `DetectionPanel.cs` : 영상 탐지 화면 (엔진 메시지를 받아 화면과 DB에 반영)
4. `Db.cs` : DB 표 만들기, 저장, 조회 SQL
5. `HistoryPanel.cs`, `StatsPanel.cs`, `SettingsPanel.cs` : 나머지 화면
6. `EngineClient.cs` : Python 엔진을 실행하고 대화하는 부분

## 6. 알려진 한계
- 학습 결과가 좋아도 head 재현율은 0.93 이라, 미착용 10명 중 약 1명은 놓칠 수 있습니다.
- 공개 데이터셋이라 실제 현장의 조명, 각도와 다를 수 있습니다. 강의실 웹캠처럼 가까운 얼굴이나 모자·로고가 있는 물체는 가끔 잘못 판정될 수 있습니다.
- 한 번에 영상(또는 웹캠) 하나만 처리합니다. 현장 CCTV 연동과 여러 카메라 동시 처리는 범위 밖입니다.
- 사람 구분은 단순한 추적(박스가 겹치는 정도)이라, 사람이 서로 가리거나 지나가면 같은 사람을 다른 사람으로 셀 수 있습니다.
- 알림은 미착용이 설정 시간에 도달한 순간에 기록하므로, 기록된 지속 시간은 설정값(기본 3초) 근처입니다.
